# AuxBass Player (Android & Flutter)

Нативный клиент для музыкального плеера [aux.ganj4craft.ru](https://aux.ganj4craft.ru).

## 🚀 Что уже сделано:
1. **Экран входа (`LoginScreen`):**
   * Фирменный темный дизайн в стиле AuxBass.
   * Инструкция по получению кода входа.
   * Кнопка прямого перехода в бота Telegram: `@auxbassbot`.
   * Поле ввода кода и обработка ошибок (например, неверный/истекший код).
2. **Сервис авторизации (`AuthService`):**
   * Запрос к `POST https://aux.ganj4craft.ru/api/auth/verify-code`.
   * Сохранение токена (`tg_player_auth_token`) и данных пользователя в локальное хранилище.
   * Проверка и валидация активной сессии через `GET /api/auth/me`.
   * Выход из аккаунта (`logout`).
3. **Шлюз авторизации (`AuthGate`):**
   * При запуске приложения проверяется, вошел ли уже пользователь. Если да — сразу открывается главный экран, без повторного ввода кода.

## 🛠 Как запустить проект:
Если у вас установлен Flutter SDK, перейдите в папку проекта:

```bash
cd ~/Проекты/aux_player

# Сгенерировать платформенные папки (android/ios), если еще не созданы:
flutter create . --platforms=android

# Установить зависимости:
flutter pub get

# Запустить на подключенном Android-смартфоне или эмуляторе:
flutter run
```
